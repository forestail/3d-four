# 3D FOUR

ブラウザで遊べる、Three.js製の立体4目並べ（Qubic）です。
4×4×4の空間に黒球を置き、縦・横・奥行き、面上の斜め、空間対角線のいずれかで4つ一直線に並べると勝利です。

## プレイ

`index.html` をブラウザで開くと遊べます。

Three.jsをCDNから読み込むため、インターネット接続が必要です。ブラウザのローカルファイル制限で動作しない場合は、次のように簡易サーバーを起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで [http://localhost:8000/](http://localhost:8000/) を開きます。

## ルール

- 4×4×4、合計64個の交点から空いている場所を選んで置きます（重力なし）。
- プレイヤーは黒、CPUは白です。
- X/Y/Z方向、面の斜め、空間の斜めのいずれかで4つ並べると勝ちです。
- 先に4つ並べると勝利、すべて埋まって並ばなければ引き分けです。

## 操作

- ドラッグ：盤面を回転
- ホイール／ピンチ：ズーム
- 空いている交点をクリック：黒球を置く
- 「最初から」：新しい対局を開始
- 「視点を戻す」：カメラを初期位置に戻す

### iPhone／タッチ端末

- PCと同じように、キューブ上の空いている交点をタップして配置場所を選択
- 選択した場所には薄い黒球が表示され、「ここに置く」ボタンで確定
- 別の高さの交点をタップすると、その交点を含む水平面のハイライトに切り替わる
- 2本指のピンチ操作でズーム、ドラッグで視点を回転
- 上部の「情報を隠す／設定」で、ゲーム情報と設定パネルを開閉
- 画面下部には、選択中の薄い黒球を確定する「ここに置く」ボタンだけを表示
- キューブの回転開始時と着手後は上部パネルが自動的に折りたたまれます
- CPUが着手した後は水平面のハイライトを解除し、キューブ全体を表示します

## CPUの強さ

- **弱い**：ランダム性が高く、勝ち手や防御を見逃すことがあります。
- **普通**：即時の勝ち・防御と、1手先の脅威を評価します。
- **強い**：フォーク（二重リーチ）の作成・防御と、より深い戦術評価を行います。

選択した難易度はブラウザのローカルストレージに保存されます。
